# Итоговая аттестация 
## Дащенко Кирилл    
##Описание программы

Данный код реализует базовую структуру данных для работы с графами, включая классы Node (узел) и Graph (граф). Предоставляется функционал для добавления и удаления узлов, а также добавления и удаления ребер между узлами. Реализован алгоритм поиска в ширину (BFS) для обхода графа.


##Требования для запуска

Установленный интерпретатор Python версии 3.6 или выше.
Отсутствие внешних зависимостей (код использует только стандартные библиотеки Python).

##Как запустить приложение

Сохраните приведенный в файле main.py код в файл с расширением .py 
Запустите файл из командной строки, используя команду: python graph_operations.py
